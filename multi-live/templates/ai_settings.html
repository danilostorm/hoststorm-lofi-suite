Motor e modo

Comece em Copilot e passe para Autopilot quando confiar no comportamento.

O marcador de IA é configurável, mas recomendamos mantê-lo. O objetivo é ser natural, não fingir que cada mensagem foi digitada manualmente por uma pessoa.

Ritmo humano

O intervalo muda a cada ciclo; a IA não responde todos os comentários.

Memória e segurança

Memória curta ajuda a continuar conversas sem mandar histórico inteiro para o modelo.

Tokens OAuth, Client Secrets, stream keys, senhas e security.key nunca fazem parte do contexto do AI Host. Mensagens do público são marcadas internamente como conteúdo não confiável.

Voz / TTS

O áudio é injetado em cada FFmpeg com ducking automático do áudio base.

Ative TTS antes de iniciar uma transmissão. O HostStorm cria um barramento de áudio por plataforma no start do FFmpeg; uma live que já estava rodando precisa ser reiniciada para receber a voz.

Visão contextual

Opcional: captura um frame ocasional, não analisa vídeo continuamente.

Um frame a cada {{settings.vision_interval_seconds}}s fornece pistas visuais para o chat sem análise contínua de 30/60 FPS. O custo principal é do provider de visão, não do FFmpeg que tira uma imagem isolada.
