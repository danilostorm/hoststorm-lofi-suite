Informe o acesso SSH uma única vez. O HostStorm prepara Docker, Agent, token e registra o nó automaticamente.

Senha SSH não é salva. Ela existe somente em memória durante o provisionamento. Depois disso, Control Plane e Agent conversam por API autenticada com token próprio.

Como o Cluster 5 funciona

Cada Destino RTMP pode escolher local, automático ou um Agent específico. O estado da saída remota é persistido para sobreviver a reinício do Control Plane.

1Bootstrap SSHinstala Docker + Agent
2HealthCPU/RAM/GPU + streams
3Placementpor saída RTMP
4Failoverpróximo Agent ou local

Arquivos locais necessários são sincronizados automaticamente antes da transmissão. Para bibliotecas muito grandes, a próxima evolução pode usar storage compartilhado/rclone para evitar cópias repetidas.
